# Movie Universe - Features Guide

## Overview
Online movie streaming platform built with Next.js.

## Features
| Feature | Description |
|---------|-------------|
| Movie Catalog | Browse thousands of movies |
| Search | Full-text search with filters |
| Streaming | HD video playback |
| Categories | Genre-based browsing |
| Responsive | Works on all devices |

## Tech Stack
| Technology | Purpose |
|-----------|---------|
| Next.js | SSR Framework |
| React | UI Components |
| TMDB API | Movie data source |
| CSS/Tailwind | Styling |

## Setup
```bash
git clone https://github.com/aakhmakhkout/Movie-Universe.git
cd Movie-Universe
npm install
npm run dev
```
